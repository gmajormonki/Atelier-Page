A quiet studio for modern music creation.

Atelier is a native-feel macOS desktop workstation bringing together on-device MLX stem separation, AI-assisted arrangement and lyric workflows, and content-addressed cloud backup in one focused workspace.

Local MLX Stem Separation

Hardware-accelerated audio separation running locally on Apple Silicon with zero cloud upload latency.

Arrangement & Lyric Studio

Structured prompt engineering, reference analysis, and Suno cover/arrangement pipelines built for songwriters.

Content-Addressed Cloud Sync

SHA-256 deduplicated bidirectional backup for audio masters, proxies, prompts, and project databases.

Google Drive Integration Notice: When explicitly authorized by the user, Atelier uses the https://www.googleapis.com/auth/drive.file and userinfo.email scopes solely to synchronize files created by Atelier inside a dedicated MusicWorkstation_Sync folder in the user's own Google Drive. Atelier never accesses unrelated Drive files.
